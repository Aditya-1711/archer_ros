# A.R.C.H.E.R. - Advanced Robotic Control with Hybrid Embedded Reasoning

> [!NOTE]
> **Status: Completed & Graded**
> This project has been successfully completed and graded as part of the coursework.

A.R.C.H.E.R. (Advanced Robotic Control with HybridEmbedded Reasoning) is an advanced humanoid robotics platform designed for intelligent interaction, spatial awareness, and autonomous task execution. 

## Overview

Archer is designed to operate autonomously within indoor environments, processing environmental data in real-time to navigate, observe, and interact with humans. Built with a focus on seamless human-robot interaction, Archer bridges the gap between complex robotics and intuitive natural language commands.

## Key Capabilities

- **Natural Language Understanding**: Archer can understand and process plain English commands, allowing users to direct the robot simply by speaking or typing.
- **Autonomous Navigation & Mapping**: Equipped with advanced spatial awareness, Archer can map its environment, determine optimal paths, and navigate autonomously to specific rooms or locations while avoiding obstacles.
- **Environmental Perception**: Archer utilizes a comprehensive vision pipeline to "see" and interpret its surroundings, enabling a semantic understanding of objects and spaces.
- **Interactive Web Control**: Users can monitor Archer's state, view real-time mapping, and manually direct the robot through a sleek, user-friendly interface.
- **Memory & Planning**: The system is capable of remembering spatial features and executing simple plans based on user requests.

## Interaction

Interacting with Archer is designed to be as natural as possible. Users can issue conversational directives such as:
* *"Archer, please go to the kitchen."*
* *"Head to the living room."*
* *"Move forward 2 meters."*

Archer responds intelligently and confirms command execution, acting as a highly capable, autonomous robotic assistant.
